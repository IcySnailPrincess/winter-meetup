# ❄️ yearly winter meet up

Availability page for Dec 15, 2026 – Jan 10, 2027: https://icysnailprincess.github.io/winter-meetup/

- `index.html`: the whole site (static, served by GitHub Pages).
- `apps-script/Code.gs`: the Google Apps Script backend. Responses are stored in a Google Sheet.
  To change it, edit the script at script.google.com, then Deploy > Manage deployments > Edit > New version.
